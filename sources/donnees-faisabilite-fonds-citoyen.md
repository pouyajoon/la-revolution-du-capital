# Données — Faisabilité d’un fonds citoyen (France)

Inventaire des prédicats, chiffres et sources utilisés pour le chapitre technique.
Dernière collecte : **13 octobre 2026**.

Les montants boursiers fluctuent chaque jour. Les calculs du chapitre sont des **ordres de grandeur**, pas des prévisions.

---

## 1. Prédicats (hypothèses de travail)

| # | Prédicat | Statut |
|---|----------|--------|
| P1 | Les contributions sont **volontaires**, sans ROI individuel. | Hypothèse de projet |
| P2 | Scénario de base = **peuple seul** : aucun leg, aucune grande fortune, aucun fonds institutionnel / de retraite / souverain / étatique. | Hypothèse de projet (centrale) |
| P3 | On pourrait plus tard agglomérer ou travailler avec des fonds institutionnels existants — **hors** de ces calculs. | Extension possible, non comptée |
| P4 | « Une personne, une voix » : le montant versé n’achète pas de pouvoir. | Hypothèse de projet |
| P5 | On calcule d’abord la **collecte brute** (hors frais de structure, fiscalité, slippage, inflation). | Simplification |
| P6 | Les cibles d’achat sont des **participations partielles** (1 % / 5 %), pas un rachat à 100 %. | Choix méthodologique |
| P7 | Le premier seuil d’influence réglementaire sur Euronext Paris est **5 %** du capital ou des droits de vote (déclaration AMF). | Droit français |
| P8 | Un panier « stratégique France » de départ : **TotalEnergies + Engie + Veolia** (énergie / multi-utilities / eau). | Choix illustratif |
| P9 | Les paliers de cotisation (5 / 10 / 20 / 100 €) sont **proposés**, pas imposés ; calibrés sur les niveaux de vie INSEE. | Hypothèse de projet |
| P10 | Les livrets A / LDDS sont une **réserve potentielle citoyenne** ; toute réallocation suppose un choix du peuple (liquidité, sécurité, usage social actuel de l’épargne réglementée). | Mise en garde |
| P11 | Les dividendes éventuels sont **réinvestis** dans le fonds (effet de levier modeste, non modélisé en détail ici). | Hypothèse de projet |
